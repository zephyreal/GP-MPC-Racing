第一次做无人车控制？从这里开始

你的任务：让车沿赛道稳定行驶，再尝试缩短用时。先学会改两个参数，不需要一开始就会 MPC 或机器学习。

你写什么，平台做什么？

你编写“驾驶策略”：根据车辆位置、速度和前方道路，决定往哪转、加速还是减速。平台提供车辆和地图，负责模拟运动、计圈和排名。你不用画车、制作地图或上传行驶数据。

输入：当前位置、速度、方向和地图 → 你的代码：作出驾驶决策 → 输出：转向和驱动/制动。

教师车和学生车在相同条件下分别运行，网页把轨迹放在同一地图比较，两车互不碰撞。先比较是否完成，再比较总模拟用时；服务器计算等待时间不计入圈速。

1. 下载并启动（只做一次准备）

  1. 从当前比赛下载完整案例包，右键“全部解压”。
  2. 电脑安装 Python 3.12，勾选 Add Python to PATH。
  3. 双击 START.bat。首次需要联网准备环境；以后仍然只打开这个文件。
  4. 先选择“1：入门演示”，在基础椭圆跑1圈，结束后自动打开结果。

基础椭圆只帮助你熟悉流程。正式比赛仍使用老师指定的地图，不能用训练地图的结果打榜。

macOS/Linux：在解压目录运行 python3 launch.py。旧的01/02/03脚本仍可使用。

2. 跟做一个完整案例：先慢一点

  1. 在启动菜单选“4：打开代码”，找到下面两行。
  2. 先用原设置在同一地图运行，保留结果作为对照。
  3. 只把 SPEED = 8.0 改为 SPEED = 7.0，保存。其余不动。
  4. 选择“2：比赛地图试跑1圈”，查看轨迹、完成圈数、用时和横向误差。
  5. 两次必须使用相同地图、圈数和规则。若仍越界，先观察越界处，再尝试调整前视距离。
SPEED = 8.0      # 想让车跑多快，单位：米/秒
LOOKAHEAD = 7.0  # 往前看多远，单位：米
修改项怎么理解观察什么
目标速度 SPEED希望车达到的速度，不是强制设置实际速度用时是否降低，弯道是否越界
前视距离 LOOKAHEAD选择前方多远的道路点作为跟踪目标转向是否抖动，是否切弯或偏离中心

速度降低不保证一定完成，前视距离也没有对所有赛道都最好的值。每次只改一个参数，才能知道变化来自哪里。

3. 看结果，然后完成正式圈数

结果页的灰色是赛道，橙线是实际行驶轨迹。首先看“是否完成”，其次看用时和横向误差。未完成的短用时不代表更快。

本地结果自动保存在 output，保留每次试跑的报告和参数，方便回看。基础试跑完成后，在启动菜单选“3：按比赛规则完整试跑”，圈数从下载包读取，通常为10圈。

赛道和车辆数据在 map.html、track.json；详细接口在 README.md。无需修改这些文件。Track02比入门地图更难，模板不保证直接完成。

4. 只上传一个文件

回到网站，选择根目录 agent.py，填写一句话：“目标速度从8改为7，其他设置不变”，点击上传。

不要上传 output、report.html、轨迹JSON、START.bat或整个案例文件夹。多文件代码项目才使用ZIP，根目录必须有agent.py。

看到“提交成功”后可以关闭网页，不必一直等待。服务器会排队计算，完成后重新打开页面查看双车回放；结课赛需要老师发布成绩。排名不是课程总成绩，请保留你的实验对比。

遇到问题怎么办？

看到的情况下一步
Python未找到安装Python 3.12并勾选PATH，然后重新打开START.bat
安装依赖失败检查网络，保留报错窗口给老师看；不要反复上传
代码报错按提示行号检查；首次只改两个数值，不改缩进和标点
车身越界先降速，并查看报告中的轨迹；再一次只改一项
排队或评测机离线文件已保存，等待老师处理，不需要再次提交
本地成功、正式失败确认下载的是当前比赛案例包；检查地图、环境和单步耗时限制

完成入门后再挑战

①调整前视距离并做对照实验；②根据前方弯道改变目标速度；③尝试新的跟踪算法。先稳定完成，再研究MPC、GP学习等方法。

允许借助AI解释代码，但你需要能说明修改原因和实验结果。只运行自己或教师提供的可信代码。

不会写无人车算法？先跟做这个案例

学习目标：让车稳定跑完，再尝试更快。你只写驾驶策略；车辆、地图、计圈和评分由平台提供。

  1. 下载、全部解压：电脑安装 Python 3.12，双击包内 START.bat，首次自动准备环境。
  2. 本机跟做：先选“1：入门演示”；打开 agent.py，把 SPEED = 8.0 改成 7.0。在同一地图重跑，比较是否完成、用时和轨迹。
  3. 试跑本场比赛：在启动菜单选“2：比赛地图1圈”，再选“3：完整试跑”。每次只修改一个参数。
  4. 上传、等结果：只上传 agent.py，不要上传整个案例包或output。提交成功即可关闭网页，之后回来查看结果。

两个参数是什么意思？结果怎么看？

SPEED：目标速度（米/秒），太快可能在弯道越界。LOOKAHEAD：前视距离（米），影响跟踪方向和转向平稳性。

先比较是否跑完，再比较用时。未完成的短用时不能当作进步。灰色是赛道，橙色是你的轨迹；第一次无需理解MPC或GP。

车身越界：先降速再调整前视距离。代码错误：检查数值、缩进和标点。排队或评测机离线：文件已保存，无需重复提交。

本地练习不限次数；正式排名按当前比赛规则。入门椭圆仅用于练习。
